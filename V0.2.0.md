# DojoMap v0.2.0

## Scope

The goal of v0.2.0 is to turn the existing curriculum into a guided journey. Students move vertically from their dojo introduction through each belt, while a persistent progression navigator shows where they are on the path to black belt.

> **v0.1.0:** The curriculum exists.  
> **v0.2.0:** The curriculum becomes a journey.  
> **v0.3.0:** To be decided after using v0.2.0.

## Experience Direction

The page is a sequence of full-screen sections:

1. **Dojo** — Introduces DojoMap, identifies Fort Myers Karate as the student's dojo, and invites the student to begin their path to black belt.
2. **White Belt** — Establishes the beginning of the journey and presents the belt's forms, techniques, and knowledge.
3. **Following Belts** — Continues through the curriculum in data-defined order.
4. **Final Rank** — Concludes the journey intentionally rather than ending abruptly.

A representative opening is:

```text
DOJOMAP

Your Dojo
Fort Myers Karate

Your Path to Black Belt
↓
```

A representative rank section is:

```text
WHITE BELT
The Beginning

Forms
• Basic Form 1

Techniques
• Front Kick ↗
• High Block

Knowledge
• Dojo etiquette
```

The progression navigator is the map of the complete journey:

```text
● White ─ ○ Yellow ─ ○ Orange ─ ○ Green ─ ○ Blue ─ ○ Brown ─ ★ Black
```

Its presentation may differ between desktop and mobile, but it must always communicate the full path and the student's current position.

## Data Model Direction

Curriculum items may optionally point toward future or external resources. The model establishes these doorways without requiring every item to have a destination.

```ts
type CurriculumItem = {
  name: string;
  type: "form" | "technique" | "knowledge";
  resource?:
    | { type: "internal"; slug: string }
    | { type: "external"; url: string };
};
```

Examples:

```ts
{
  name: "Roundhouse Kick",
  type: "technique",
  resource: { type: "internal", slug: "roundhouse-kick" },
}

{
  name: "Basic Form 1",
  type: "form",
  resource: { type: "external", url: "https://example.com/basic-form-1" },
}

{
  name: "Dojo Etiquette",
  type: "knowledge",
}
```

External resources may be exposed as working links in v0.2.0. Internal resource metadata is stored for future use but is not exposed until its destination exists.

## Out of Scope

Version 0.2.0 does **not** include:

- technique, form, or knowledge detail pages;
- a technique or content library;
- search;
- student or instructor accounts;
- progress tracking or completion checkmarks;
- authentication;
- a database;
- administration tools;
- curriculum editing or other CRUD operations;
- multiple selectable dojos; or
- AI features.

In particular, DM-033 defines future-facing internal link metadata only. It does not authorize building `/techniques/[slug]` or any equivalent content route.

## Definition of Done

Version 0.2.0 is complete when every work item above meets its testable outcome, the curriculum works as an accessible journey on phone and desktop widths, the production checks pass from a clean checkout, the public deployment is verified, and the deployed commit is tagged `v0.2.0`.

The scope of v0.3.0 will be decided only after v0.2.0 has been deployed and used.
