# DojoMap v0.4.0

## Scope

The goal of v0.4.0 is to evolve DojoMap from a single-dojo curriculum experience into a small dojo-discovery product. DojoMap becomes the public entry point, while the existing Fort Myers Karate journey moves intact to its own dojo route.

> **v0.1.0:** The curriculum exists.  
> **v0.2.0:** The curriculum becomes a journey.  
> **v0.3.0:** Techniques gain focused detail.  
> **v0.4.0:** DojoMap becomes a place to discover dojos.

## Experience Direction

The root route becomes a standalone DojoMap landing experience. Its first viewport must establish the product identity and let a visitor begin searching immediately. Primary navigation provides three clear paths:

1. **Search Dojo** — Find a dojo by name or location.
2. **Explore Dojos** — Browse the available directory.
3. **I Own a Dojo** — Learn how a dojo may eventually join DojoMap.

The supplied reference image establishes a cinematic, disciplined direction: high-contrast black and white, strong editorial typography, restrained red accents, martial-arts imagery, and search as the dominant action. It is visual inspiration rather than a pixel-for-pixel specification. The implementation must preserve DojoMap's own identity, readable content, accessible contrast, responsive behavior, and honest product scope.

The landing experience should feel substantial without implying features that do not exist. Search operates only over the static directory, and the owner path explains a future offering rather than pretending onboarding is available.

## Route Ownership

The v0.4.0 routes have distinct responsibilities:

```text
/                     DojoMap landing and dojo search
/dojos                Browsable dojo directory
/for-dojos            Information for dojo owners
/fort-myers-karate    Existing Fort Myers Karate curriculum journey
```

The root route no longer renders the Fort Myers Karate curriculum. Moving that experience must not change its curriculum order, snap scrolling, progression navigation, technique details, resource behavior, keyboard support, or responsive treatment.

Unknown dojo slugs must not fall through to a broken curriculum. They receive an intentional not-found experience with a route back to dojo discovery.

## Directory Model Direction

Static directory data is the source of truth for dojo discovery and route resolution. A dojo record must contain enough information to power search results, discovery cards, and its route without duplicating the dojo identity across components.

The exact TypeScript representation is decided in DM-075, but it must support the equivalent of:

```ts
type DojoDirectoryEntry = {
  id: string;
  slug: string;
  name: string;
  location: {
    city: string;
    region: string;
  };
  discipline: string;
  summary: string;
};
```

Fort Myers Karate is the only required directory entry for v0.4.0. The model must support more entries later, but this release does not require inventing placeholder dojos or adding persistence.

## Search Contract

Search is a small, local discovery tool:

- matching is case-insensitive;
- a visitor can find Fort Myers Karate by its name and relevant location text;
- blank queries do not produce a misleading result state;
- no-match searches show an intentional empty state and a path to browse the directory;
- selecting a result navigates to the dojo's canonical slug route; and
- results come from the directory data rather than component-specific hard-coding.

Search suggestions, geolocation, distance sorting, maps, autocomplete services, and remote search infrastructure are outside this release.

## Out of Scope

Version 0.4.0 does **not** include:

- accounts, authentication, or user profiles;
- student progress tracking or completion state;
- dojo-owner sign-up, onboarding, claiming, verification, or dashboards;
- curriculum or dojo administration and other CRUD operations;
- a database or remotely managed directory;
- payments, subscriptions, pricing, or billing;
- geolocation, maps, directions, or distance-based search;
- reviews, ratings, favorites, or recommendations;
- messaging or lead-management workflows;
- user-submitted dojo listings;
- multiple complete dojo curricula—the only required curriculum remains Fort Myers Karate;
- a technique library or standalone technique routes;
- AI-generated instruction or content; or
- an attempt to map every dojo, martial art, or lifetime training outcome.

The static directory establishes a scalable product boundary without pretending the broader marketplace, owner platform, or data infrastructure already exists.

## Definition of Done

Version 0.4.0 is complete when every work item above meets its testable outcome; visitors can discover and open Fort Myers Karate from the new DojoMap landing and directory experiences; the existing curriculum journey remains intact at its canonical dojo route; all new routes are responsive and accessible; production checks pass from a clean checkout; the public deployment is verified; and the deployed commit is tagged `v0.4.0`.

The scope of v0.5.0 will be decided only after v0.4.0 has been deployed and used.
